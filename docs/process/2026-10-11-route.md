# Yamanote route load — 2026-10-11

> Updated on 2026-10-12: the hook now covers any InGame world, refuses
> `UnloadStreamLevel` and hidden preloads, leaves lighting levels to the
> mission, and resets on OutGame. See `2026-10-12-touch-vsync-route.md`.

Target is TG4AC 5.80.02, IDA instance `ida-35608`, image base `0x140000000`.
Content is loose uassets (`UsePakFile=False`). The hook lives in
`dll/src/features/route`. `[Route] Enabled=0` installs nothing.

## How a mission picks a section

`GetStationIntervalData` (`sub_1401C42B0`, RVA `0x1C42B0`) looks up one row by
mission id and station index. The row is 72 bytes in the table. The copy into
the output struct is:

| Offset | Field |
| --- | --- |
| `+8` | MissionId |
| `+12` | StationIndex |
| `+16` | BeginStationId |
| `+20` | EndStationId |
| `+24` | PrevStationId |
| `+28` | NextStationId |
| `+32` | WeatherType |
| `+36` | timelimit |
| `+48` | WaitNextSection |
| `+49` | UnloadPrevSectionRunning |

`GetSectionLength` (`sub_1401C3FE0`, RVA `0x1C3FE0`) returns that mission's
`SectionCount`, the number of interval rows. It is not a distance in meters,
so the hook does not change it. A larger count without extra rows would make
the next index miss.

The level name is `StationData.LevelName` (short codes such as `TKYc`,
`SINc`). `EMissionLineType::YMTc` is 6. The blueprint
`LevelLoadProcessor` asks for the current station plus the previous and next
neighbors only. `StationIntervalData.UnloadPrevSectionRunning` is what sends
the previous block to release.

The current loop is the `YMTc` packages (the `c` suffix). `InGame.umap` still
lists the older partial `YMT` slice (Harajuku, Shibuya, Ebisu, Meguro, and so
on). That older slice is not the full loop.

## Streaming model

Gameplay streaming is a persistent level plus `ALoadLevelManager`, not world
composition. World-composition strings exist in the engine and are unused here.

`Content/Maps/InGame/YMTc/YMTc.umap` is the loop world. It already names every
YMTc station as a streaming sublevel. Each station umap nests its own children
(`_Stage`, `_Gimmick`, `_Camera`, and the `X_YMTc` section pieces). A mission
only marks current, previous, and next as loaded.

`LevelLoadStart` (`sub_1401FDA20`, RVA `0x1FDA20`) forwards to
`sub_1401FDA40` with the queue flag set. The cheat `LoadStreamLevel`
(`sub_1401FEA20`) can only show levels that are already on
`UWorld::StreamingLevels`, so it is not the loader. Async loading time limits
are unchanged.

`FName` helpers, UE 4.15, `FNAME_Add = 1`:

| Helper | Address | RVA |
| --- | --- | --- |
| Make name | `sub_14052EC80` | `0x52EC80` |
| Name to string | `sub_140533220` | `0x533220` |
| Free wide data | `sub_140489F70` | `0x489F70` |

## What unloads the previous block

`LevelRelease` (`sub_1401FDBC0`, RVA `0x1FDBC0`) decrements the refcount and,
at zero, calls `sub_140201DA0`. That drop is the unload. `sub_140201DA0` has
no other caller. `LevelReleaseStart` (`sub_1401FDE30`, RVA `0x1FDE30`)
enqueues the same name for the serial release worker and returns whether the
in-flight counter at manager `+1120` was zero.

## Hook

`[Route] Enabled=1` installs three hooks. `Enabled` missing or not `1` returns
before `MH_CreateHook`.

On the first `LevelLoadStart` whose `FName` contains `YMTc`, `/YMT/`, or
`YMT_`, or whose last path component is `YMTc` or one of the queued package
leaves (`SINc`, `SINc_Stage`, and the rest), the detour calls the original
for that request and then queues every package in `route_packages.inc` with
`prevFlag = 0`. Each queued path is logged as `Route: loaded <path>`. The
extra calls go through the trampoline, so they do not expand again.

`LevelRelease` for those names returns without calling the original, so the
refcount never reaches zero. `LevelReleaseStart` for those names returns true
and does not enqueue them. The first refused release logs
`Route: LevelRelease ignored for Yamanote packages`.

## Packages that stay loaded

353 packages, from `YMTc.umap` and the station umaps under the same prefixes.
`/Game/Maps/InGame/YMTc/YMTc` is the persistent world and is not queued.
`*_BuiltData` packages are map-build registries, not streaming levels, and are
not queued either.

| Group | Count | Prefix |
| --- | --- | --- |
| Station maps and children | 108 | `/Game/Maps/InGame/YMTc/` |
| Section geometry | 215 | `/Game/X_YMTc/Maps/InGame/Sections/` |
| Weather lighting | 24 | `/Game/Maps/InGame/LightingYMTc/Section/` |
| Section lighting | 6 | `/Game/SectionLighting/YMTc/` |

The 24 weather maps are four scenarios (Cloudy, Morning, Sunny, Sunset) for
six blocks: `HMMc_TKYc`, `SGWc_SHNc`, `SINc_SBYc`, `TKYc_UENc`, `UENc_TBTc`,
`YIKc_SINc`. They are all queued visible. The mission's own light-map change
still selects a weather; this hook does not hide the other three, so those
weathers can stack.

`NNPc` and `TBTc` have no station root umap in this set. Their geometry is
`NNPc_StaticGimmickC`, `TBTc_StaticGimmickC`, and the `X_YMTc` section pieces
(`NNPc_A` through `NNPc_enlivening`, `TBTc_A`, `TBTc_D`, `TBTc_S`).

The full-loop splines are `YMTc_Inner` and `YMTc_Outer` under
`Content/Blueprints/PathOperation/railspline/ymtc/`. The hook does not retarget
them. The mission still samples the interval stored for its
`BeginStationId` and `EndStationId`.

## What still ends a section

The track graph is not one native function that can be extended. The loaded
levels stay resident, and the train still stops at the mission interval.

`TrainPawn::SetDistance` (`sub_140255550`, RVA `0x255550`) writes the float
at train `+1336` and, when the third argument is clear, broadcasts through
`sub_1401A89A0` at train `+1528`. It does not clamp.

`SectionComponentBase::SectionEnd` is a blueprint event. `sub_14040E8B0`
(RVA `0x40E8B0`) builds that `UFunction` with flags `134350848` and an
`EndPlayReason` parameter. `sub_14033D0D0` registers the names `SectionBegin`,
`SectionEnd`, `SectionOverrunValue`, and `SectionUpdate`. There is no native
body to hook.

`GetRemainDistance` (`0x1423e5448`) has a single data xref, inside the
`UFunction` constructor `sub_14030D410`. There is no compact native
implementation. The blueprint signal is `RemainDistancePointDelegate` with
`bIsLastPoint`, fed by the interval row from `sub_1401C42B0`.

That row's `EndStationId` is the boundary that still stops the train.
