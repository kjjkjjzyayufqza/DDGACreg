## What this project is

A `version.dll` MinHook proxy plus a separate localhost content server.
The display path follows Spencer Miller's DDGUltrawide (MIT), not an ASI plugin.
Ultimate ASI Loader is only a style reference for "DLL sits next to the EXE and
hooks the process." This repo does not emit `.asi` files and does not scan an
`scripts` / `plugins` folder.

## UE4SS reflection already on disk

`UE4SS_ObjectDump.txt` and `Mods/shared/types/*.lua` name the gameplay types.
These are reflection names, not native addresses. IDA has to bind them to code.

### Coin

- `UCreditsManager` (`Mods/shared/types/CreditsManager.lua`)
  - `CoinNumChangeDelgate(Num, increase)`
  - `GetInsertedCoin`, `DecreaseCoin`, `InsertServiceCoin`
  - fields: `MaxCoin`, `LastCoinNum`, `serviceNum`
- Delegates in the object dump:
  - `/Script/TG4AC.IOCoinDelegate__DelegateSignature` (`inc`, `Num`)
  - `/Script/TG4AC.KBCoinDelegate__DelegateSignature` (`inc`, `Num`)
- HTTP credit calls: `Http_InsertCredit`, `Http_AddCredit`,
  `Http_NesysIncomeStart`, `Http_NesysIncomeEnd`

Keyboard coin is a first-class delegate (`KBCoin`), separate from the cabinet
IO coin line (`IOCoin`). The default binding for this mod is F3, overridable
from `config.ini` `[Input]`.

### Camera

- `NativePlayerCameraManager` extends `PlayerCameraManager`
- `CameraControlActorBase`, `CameraLevelControlActor`
- `CameraComponentCustomizerBase` is what `UAdjustCamera` drives:
  FOV, HRZ, VCL, SCL, AGLX, AGLY, Yaw, HGT, SDE
- `NativePhotographyCamera` exists and is a different mode (photo), not the
  free-fly camera

Free camera should move the active view (`NativePlayerCameraManager` /
camera component transform), with WASD, mouse look, Shift, Ctrl, Space, and a
descend key. It must not reuse the photography mode unless IDA shows that mode
is the only writable view.

### Display

DDGUltrawide already documents the cabinet frame: 3840x2160, four 1920x1080
panels in a 2x2 grid (left, center, right, touch). This repo keeps that
compositor and adds:

- preset `32:9` (the upstream arcade ultrawide layout)
- preset `16:9`
- preset `single`, focused panel switched with the arrow keys

production game host is `0x14022943D`. After the table copy, the same function

NESiS certificate update URL fragment `://cert.nesys.jp/update/cgi/` is used
by `sub_1402410C0`. That path is not the gameplay content API. The local
server implements `/ahac-api/tg4gs/gs` only, and it binds to localhost.

### Content commands

Commands are ASCII literals widened by `sub_140198080` inside tiny stubs
(size about `0x4B`). Confirmed stubs:

| Command | Stub | String |
| --- | --- | --- |
| addcredit | `sub_140221E20` | `0x14239AD40` |
| login | `sub_140221F50` | `0x1423982B0` |
| gamestart | `sub_140223250` | `0x142398478` |
| getmissionranking | `sub_140222040` | `0x14239A0B0` |
| getstoremileageranking | (xref `0x140223183`) | `0x14239C170` |

Function pointers for `login` and `addcredit` sit in `.rdata` at
`0x1423D1A50` and `0x1423D1F68`.

Ranking replies are JSON-like objects. `sub_140211C80` reads `start_at`,
`end_at`, `update_at`, and a `ranking` array. Timestamps are unix
milliseconds, converted with the +9h offset `324000000000` (100ns units).

`insertcredit`, `selectcard`, and `KBCoin` did not appear as ASCII strings
in this pass. Card and coin names are visible to UE4SS reflection, so the
native side likely keeps them in the FName pool or as UTF-16 only.
